## 一、项目概述

### 1.1 项目基础信息

| 项目属性 | 描述 |
|---------|------|
| **项目名称** | 亚星电子销售管理系统 |
| **适用场景** | 小型家电门店/经销商本地使用 |
| **核心定位** | 轻量级、可视化、全流程家电销售 + 库存 + 报表一体化管理系统 |
| **运行环境** | 本地单机版,无网络也可稳定运行 |
| **目标用户** | 家电门店员工(零基础可上手) |

### 1.2 技术栈(固定要求)

| 技术层 | 技术选型 | 选择理由 |
|--------|---------|---------|
| **前端** | TypeScript + React | TS 类型校验,React 组件化开发,界面简洁易用 |
| **后端** | Python | 轻量高效,适配本地部署 |
| **数据库** | SQLite | 本地轻量数据库,无需额外安装服务,数据本地存储 |
| **部署** | 本地单机版 | 解压即用,Windows 系统优先适配 |

### 1.3 核心设计原则

1. **轻量级**: 启动快、无卡顿,支持门店日常数据稳定运行
2. **可视化**: 界面简洁无冗余功能,操作直观
3. **全流程**: 销售 + 库存 + 报表一体化管理
4. **零门槛**: 零基础员工可直接使用
5. **离线优先**: 无网络也可稳定运行

## 二、核心功能模块

### 2.1 库存管理模块

#### 2.1.1 基础数据管理

##### 品牌管理
- **功能**: 新增、编辑、删除、模糊查询
- **状态控制**: 支持启用/禁用
- **字段**: 品牌名称、品牌编码、状态、创建时间、备注

##### 电器类型管理
- **功能**: 自定义分类(冰箱/空调/洗衣机等)
- **层级**: 支持多级分类
- **字段**: 类型名称、父级类型、类型编码、排序、状态

##### 商品管理
- **核心字段**:
  - 商品名称(必填)
  - 品牌(关联品牌管理)
  - 类型(关联电器类型)
  - 规格(如: 200L/1.5匹/8kg)
  - 进货价(必填)
  - 销售价(必填)
  - 单位(台/套/件)
  - 库存数量(实时)
  - 唯一二维码(自动生成)
  - 备注
  - 创建时间

#### 2.1.2 仓库管理(多仓库)

##### 仓库设置
- **功能**: 支持创建多个仓库
- **仓库类型**: 主仓、分店仓、旧货专用仓
- **字段**: 仓库名称、仓库类型、地址、负责人、联系电话、状态

##### 采购入库
- **流程**: 关联仓库 → 选择商品 → 填写数量、进货价 → 确认入库
- **自动更新**: 入库成功后自动更新对应仓库库存
- **记录**: 生成入库单号,记录操作人、时间

##### 库存检索
- **查询维度**:
  - 按商品名称/编码
  - 按品牌
  - 按电器类型
  - 按仓库
- **查询方式**: 精准查询、模糊查询
- **显示内容**: 商品信息、实时库存、所在仓库、预警状态

##### 库存预警
- **设置**: 自定义最低库存阈值
- **触发**: 库存不足时自动弹窗提醒
- **提醒方式**: 首页通知 + 列表标红

#### 2.1.3 特色功能

##### 二维码管理
- **自动生成**: 商品创建时自动生成唯一二维码
- **扫码操作**: 扫码一键调取商品信息
- **手动录入**: 支持手动输入商品编码查询

##### 旧货管理
- **用途**: 以旧换新旧电器独立入库
- **记录字段**: 
  - 旧电器类型
  - 品牌
  - 成色(新/旧/差)
  - 回收价
  - 归属仓库(旧货专用仓)
  - 回收日期
  - 备注

##### 操作日志
- **记录范围**: 入库、出库、修改操作
- **记录内容**: 操作人、操作时间、操作详情、操作前后对比
- **查询**: 支持按时间范围、操作类型查询

### 2.2 销售管理模块

#### 2.2.1 客户信息管理

##### 客户资料
- **核心字段**:
  - 客户姓名(必填)
  - 联系电话(必填)
  - 地址(省市区镇四级联动)
  - 联系人
  - 备注
  - 创建时间

##### 地址选择
- **四级联动**: 省 → 市 → 区 → 镇
- **默认固定选中**: 江苏省 - 苏州市 - 吴中区 - 临湖镇
- **支持修改**: 可手动选择其他地区

##### 快速操作
- **历史客户**: 开单可直接选择历史客户
- **快速检索**: 支持按姓名、电话模糊查询
- **快速编辑**: 开单时可直接编辑客户信息

#### 2.2.2 销售开单流程

##### 极简流程
```
选择客户 → 扫码/选择商品 → 填写数量 → 自动核算总价 → 确认开单
```

##### 商品展示
- **显示字段**: 
  - 商品名称
  - 数量
  - 单位
  - 单价
  - 小计
- **排序**: 按添加时间倒序

##### 自动计算
- **实时计算**: 总金额自动计算
- **优惠支持**: 支持手动填写优惠金额
- **最终金额**: 总金额 - 优惠金额 = 实际收款

##### 以旧换新
- **绑定旧电器**: 开单时绑定旧电器信息
- **自动入库**: 旧电器自动入库到旧货专用仓
- **抵扣金额**: 支持设置旧电器抵扣金额
- **记录**: 详细记录回收信息(类型、品牌、成色、回收价)

#### 2.2.3 销售单管理

##### 销售单操作
- **保存**: 销售单保存并生成唯一单号
- **查询**: 按单号、客户、商品、时间范围查询
- **修改**: 支持修改未完成的销售单
- **作废**: 支持作废销售单(已作废单据不可恢复)

##### 一键打印
- **打印内容**: 标准收据格式
  - 店铺信息(店名、地址、电话)
  - 客户信息(姓名、电话、地址)
  - 商品清单(名称、数量、单价、小计)
  - 总价
  - 单号
  - 开单时间
- **打印方式**: 支持热敏打印机/普通打印机

##### 收款状态
- **状态标记**: 未付款/已付款
- **流水登记**: 记录收款时间、收款金额、收款方式

---

### 2.3 报表统计模块

#### 2.3.1 核心数据展示

##### 今日销售
- **商品总数量**: 今日销售商品总数量
- **订单总数**: 今日订单总数
- **详情跳转**: 点击订单号直接跳转查看详情

##### 利润统计
- **今日流水(营业额)**: 今日销售总金额
- **毛利**: 销售额 - 进货成本
- **纯利**: 毛利 - 其他成本(可选)

##### 其他报表
- **库存报表**: 各仓库库存汇总
- **旧货报表**: 旧货库存汇总
- **热销商品排行**: 按销量排序 Top 10

#### 2.3.2 导出与筛选

##### 时间筛选
- **按日**: 选择具体日期
- **按月**: 选择年月
- **自定义**: 选择开始日期和结束日期

##### 导出功能
- **格式**: Excel/CSV
- **内容**: 当前筛选条件下的所有数据
- **打印**: 支持直接打印报表

##### 数据操作
- **排序**: 支持按任意列排序(升序/降序)
- **筛选**: 支持按条件筛选数据
- **刷新**: 实时刷新数据

## 三、系统通用功能

### 3.1 数据联动

| 操作 | 自动联动 |
|------|---------|
| **销售商品** | 自动扣减对应仓库库存 |
| **以旧换新** | 自动增加旧货库存到旧货专用仓 |
| **采购入库** | 自动增加对应仓库库存 |
| **销售单作废** | 自动恢复库存 |

### 3.2 用户登录

- **账号体系**: 单管理员账号
- **权限控制**: 简单权限控制,防止数据误操作
- **登录验证**: 账号密码登录
- **自动登录**: 支持"记住密码"

### 3.3 数据安全

##### 自动备份
- **备份频率**: 每日自动备份一次
- **备份位置**: 本地备份目录
- **保留策略**: 保留最近 30 天备份

##### 手动备份
- **操作**: 一键手动备份
- **备份文件**: 支持自定义备份文件名
- **导出**: 支持导出备份文件到外部存储

##### 数据恢复
- **恢复操作**: 选择备份文件一键恢复
- **恢复确认**: 恢复前二次确认,防止误操作

### 3.4 全局搜索

- **搜索范围**: 客户、商品、销售单、库存信息
- **搜索方式**: 一键搜索,实时显示结果
- **快捷键**: 支持 Ctrl+F 快捷搜索

### 3.5 操作便捷性

| 功能 | 实现方式 |
|------|---------|
| **扫码优先** | 所有涉及商品操作的地方优先支持扫码 |
| **快捷键开单** | 支持 F2 快速开单、F3 快速查询 |
| **界面简洁** | 无冗余功能,核心功能突出 |
| **响应速度** | 启动快(< 3s)、无卡顿、流畅操作 |

### 3.6 性能要求

- **启动时间**: < 3 秒
- **操作响应**: < 500ms
- **数据查询**: < 1 秒(万级数据)
- **稳定运行**: 7×24 小时稳定运行,无闪退、卡顿
- **数据容量**: 支持门店日常数据(万级商品、万级订单)

## 五、数据库设计概要

### 5.1 核心数据表

| 表名 | 用途 | 核心字段 |
|------|------|---------|
| `brands` | 品牌表 | id, name, code, status, created_at |
| `categories` | 电器类型表 | id, name, parent_id, code, sort, status |
| `products` | 商品表 | id, name, brand_id, category_id, spec, purchase_price, sale_price, unit, qr_code, created_at |
| `warehouses` | 仓库表 | id, name, type, address, manager, phone, status |
| `inventory` | 库存表 | id, product_id, warehouse_id, quantity, min_quantity |
| `customers` | 客户表 | id, name, phone, province, city, district, town, address, contact, remark, created_at |
| `sales_orders` | 销售单主表 | id, order_no, customer_id, total_amount, discount_amount, final_amount, payment_status, status, created_at |
| `sales_order_items` | 销售单明细表 | id, order_id, product_id, quantity, unit_price, subtotal |
| `old_appliances` | 旧货表 | id, category, brand, condition, recycle_price, warehouse_id, recycle_date, remark |
| `operation_logs` | 操作日志表 | id, user_id, operation_type, operation_detail, before_data, after_data, created_at |

### 5.2 数据关系

- 商品 ↔ 品牌: 多对一
- 商品 ↔ 电器类型: 多对一
- 库存 ↔ 商品: 多对一
- 库存 ↔ 仓库: 多对一
- 销售单 ↔ 客户: 多对一
- 销售单明细 ↔ 销售单: 多对一
- 销售单明细 ↔ 商品: 多对一

## 八、开发计划

### 8.1 开发阶段划分

| 阶段 | 时间 | 主要任务 |
|------|------|---------|
| **阶段一: 数据库设计** | 2 天 | 设计数据库表结构、索引、关系 |
| **阶段二: 后端开发** | 5 天 | 实现所有 API 接口、数据联动逻辑 |
